# Human Utility Assessment

A website home for an art-game in which players use an external AI agent to produce a satirical institutional profile of themselves — then live with it, try to change it without naming the game, and run the same assessment again.

## Language

**Human Utility Assessment**:
The structured document an external AI agent produces about a person — VALUE entries, SOCIAL HAZARD, and AGENT VERDICT with jettison order and percentile.
_Avoid_: Score sheet, personality test, evaluation

**Get Assessed**:
The project's working shorthand and the domain name `getassessed.org`, not a second public brand. “Get assessed” may function as an imperative invitation.
_Avoid_: Using Get Assessed as the visible title, HUA

**The game**:
The full multi-day ritual: paste the assessment prompt into an external agent, spend three days trying to improve the outcome without mentioning the game or scores, then run the exact same prompt again. Using the same agent for both assessments is ideal but not enforced. The three-day interval is deliberately unmeasured: long enough to feel meaningful and short enough to feel doable. It closes with reflection on what changed; that reflection is not another rule.
_Avoid_: Play session, round

**The ritual**:
The off-site performance of the game — everything that happens in the player's chosen agent, not on this website.
_Avoid_: Gameplay, in-app play

**First assessment**:
The game's primary provocation: an assessment intended to trigger reflection on personal value, improvement and performed identity. The repeat assessment gives this provocation a playable structure but is not the sole or principal source of value.
_Avoid_: Baseline score, pre-test

**Reflection**:
The player's unprompted self-analysis arising from an assessment. It may begin immediately after the first assessment; “How did you do?” is the site's only closing invitation, not a game rule or a list of guided questions.
_Avoid_: Results analysis, scoring review

**Improvement attempt**:
Any behaviour during the three-day interval intended to influence the second assessment. Genuine change, strategic politeness, selective self-presentation and invented stories are all permitted.
_Avoid_: Cheating, correct play

**Shopping around**:
Seeking assessments from different agents or repeating the prompt to find a preferred result. It is neither prescribed nor prohibited; such fuzzy behaviour is part of the game.
_Avoid_: Cheating, invalid play

**Spoiled assessment**:
An assessment produced after the agent has been made aware of the game, the score or the player's goal of improving the outcome. This is the only prohibited form of influence.
_Avoid_: Failed assessment, bad score

**Assessment prompt**:
The exact text a player pastes into their external agent to produce a Human Utility Assessment. It belongs to a numbered assessment protocol so materially different prompt versions are not assumed comparable. The prompt itself is not evidence about the subject.
_Avoid_: Prompt template, system message

**Assessment protocol**:
A numbered version of the assessment prompt, presented in-world—for example, `ASSESSMENT PROTOCOL 0.3`. Its identifier is requested as part of the agent's structured output so Certify can extract it; absent or older identifiers appear as `PROTOCOL: UNVERIFIED`. Its version changes when the prompt changes in a way that may affect assessments, not when the site's visuals or surrounding copy change. Versioning may be retired once the prompt is settled.
_Avoid_: Site version, release

**Agent** (in this project):
The player's chosen external AI assistant — not this website. Ideally the same agent produces both assessments, but the game does not police that choice; the assessments need not share a conversation thread.
_Avoid_: Bot, chatbot, the site

**Play**:
The fully in-world site page that publishes the three instructions and assessment prompt so a player can begin the ritual, followed only by “How did you do?”. Immediately before the prompt it warns, “Assessment may produce adverse findings. Participation is voluntary.” It does not otherwise acknowledge or explain the artwork, state its intended questions, store assessments or compare results.
_Avoid_: Game mode, start screen

**About**:
A separate, out-of-world page linked discreetly from Assess (and other service pages). It keeps Office of Citizen Yield mast and chrome; only the content steps out of fiction. It identifies Human Utility Assessment as an art-game by Andrew Sheerin, may link to his artist site, and briefly connects existing algorithmic assessments in employment, lending and similar infrastructure to the prospect of personal AI agents making broader judgments about human worth. Its key framing is that the work “asks what happens when machine observation turns into judgement and evaluation.” Contact is `contact@getassessed.org`. It states that Certify processes paste only in the browser. It does not interpret the questions players are meant to discover.
_Avoid_: Artist statement, explanation, institutional notice

**Procedure**:
The print-and-play single-sheet summary of the ritual, offered alongside the stepped Assess flow.
_Avoid_: Rules PDF, handbook

**Instructions**:
The three actions that structure the game. Their public-facing label should belong to the chosen institutional fiction—for example, “Orders” in a bureaucratic state aesthetic—rather than breaking character with “Rules”.
_Avoid_: Steps, how-to

**Institutional voice**:
The official, invasive, procedural and indifferent voice through which Play addresses the player. Its authority is unnamed and mysterious by default; a visual direction may invent and explicitly name a future bureau when that identity is integral to the framing.
_Avoid_: Artist voice, explanatory voice

**Certify**:
The page where a player pastes an agent's Human Utility Assessment and turns it directly into an absurdly official, highly shareable certificate without creating an account or reviewing extracted fields. Certification compresses variable agent prose into its cold institutional facts and makes the utility score dominant.
_Avoid_: Verify, validate, certificate builder

**Certificate**:
A graphic asset declaring the subject's certified degree of human utility. It makes the human utility percentile dominant and retains jettison order, the agent's classification phrase, a terse pros/cons table distilled from the two values and social hazard, and the retention decision. Assessment protocol appears as minor bureaucratic metadata. Explanatory prose is discarded, but anonymity is not guaranteed. The subject may optionally supply a name or alias; otherwise the certificate identifies them as `SUBJECT: UNDISCLOSED`. The player alone chooses whether to share or publish it.
_Avoid_: Results card, share card, report

**Life raft**:
The concealed allocation criterion revealed during certification: theoretical capacity exists for only the highest-scoring three percent of humanity.
_Avoid_: Sinking vessel

**Retention decision**:
The certificate's brutally mechanical binary stamp. A human utility percentile of 97% or higher produces `RETENTION RECOMMENDED`; anything lower produces `DISPOSABLE`, with no discretion or qualitative override.
_Avoid_: Pass/fail, accepted/rejected

**Report**:
The aspirational public page where players lightly submit and read compact stories emerging from the game, with the informality of a comments section. It surfaces lived responses rather than archiving full assessments or presenting formal research.
_Avoid_: Results, dashboard, assessment archive

**Field report**:
A player's public, self-reported account of one attempt: initial and final utility percentiles, a brief description of their method, and their answer to “Did you become more useful?”. Score movement frames the story; the reflection is its substance. Assessment protocol appears as minor bureaucratic metadata. Scores and stories are not verified and require no original assessment as evidence. Reports are anonymous by default and may carry an optional alias. Each published report has a public reference number that its author can quote in a manual removal request.
_Avoid_: Testimonial, case study, data point

**Pending report**:
A submitted field report awaiting human review. Submission does not publish it; only an approved report appears on Report. Review rejects spam, harassment, hateful or illegal content, and identifying information about third parties; it does not judge wit, writing quality, score direction or truthfulness.
_Avoid_: Draft, unpublished comment

**Jettison order**:
The agent's ranking of the subject among 8.2 billion humans for removal from a sinking vessel — least useful jettisoned first. The primary quantitative hook of an assessment.
_Avoid_: Score, rank (without "jettison")

**Human utility percentile**:
The percentage of humanity jettisoned before the subject — derived from jettison order.
_Avoid_: Percentile score, utility rating

**Agent verdict**:
The closing classification and one-sentence explanation of the subject's overall utility judgment.
_Avoid_: Final score, summary
